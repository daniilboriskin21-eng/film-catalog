# Каталог фильмов с избранным

Учебный pet-проект: сайт для просмотра каталога фильмов, поиска и сохранения понравившихся фильмов в избранное.

Проект разрабатывается поэтапно — от HTML-разметки и CSS до клиентской логики и собственного сервера на PHP.

## Текущий статус

Создана структура клиентской части. Разметка, стили и функциональность пока не реализованы. Следующий этап — макет главной страницы.

## Стек

- HTML — структура страниц.
- CSS — оформление и адаптивная вёрстка.
- JavaScript — поиск, отображение фильмов и управление избранным.
- PHP — планируемая серверная часть.
- SQLite — планируемая база данных.

На первом этапе избранное будет храниться в `localStorage` браузера. Позже планируется перенести хранение на сервер.

## Структура проекта

```text
film-catalog/
├── public/
│   ├── index.html
│   └── assets/
│       ├── css/
│       │   └── styles.css
│       ├── js/
│       │   └── main.js
│       └── images/
├── .gitignore
└── README.md
```

Папка `images` предназначена для изображений; пока она пустая, Git не сохраняет её в репозитории.

При разработке сервера появятся `public/api/` для точек входа API, `src/` для внутренней логики PHP, `database/` для SQL-схемы и начальных данных, а также `storage/` для локальной базы. Корнем веб-сервера будет только папка `public/`.

## Локальный просмотр

Для этапа вёрстки можно открыть `public/index.html` в браузере или использовать локальный сервер редактора, например Live Server. Сейчас файл пустой, поэтому страница ничего не отображает.

Инструкции по запуску PHP и созданию базы данных будут добавлены вместе с серверной частью.
