# КиноПолка — каталог фильмов с избранным

Учебный pet-проект на HTML, CSS, JavaScript и PHP. Каталог хранится в SQLite, PHP API возвращает фильмы в JSON, а клиент создаёт карточки из HTML-шаблона.

## Возможности

- Адаптивная сетка карточек с постерами, названием, годом, жанром и рейтингом.
- Поиск по части названия без учёта регистра и пробелов по краям запроса. Поиск запускается кнопкой «Найти» или клавишей Enter.
- Добавление и удаление фильмов из избранного, счётчик выбранных фильмов.
- Переключение между полным каталогом и избранным с сохранением поискового запроса.
- Сохранение избранного в `localStorage` и восстановление после перезагрузки.
- Сообщения о загрузке, ошибке запроса и пустом результате.
- Обработка ошибок чтения и записи избранного, а также ошибок базы в API.

Избранное хранится только в текущем браузере для конкретного адреса сайта, включая порт. Аккаунтов и синхронизации между устройствами пока нет. Рейтинги в начальных данных демонстрационные.

## Стек

- HTML и CSS — разметка и адаптивное оформление.
- JavaScript (ES-модули) — интерфейс, фильтрация, `fetch` и `localStorage`.
- PHP и PDO — API и работа с базой.
- SQLite — файловая база каталога.

Сборка фронтенда, npm и Composer для текущей версии не требуются.

## Локальный запуск

Команды ниже выполняются в PowerShell из корня проекта. Проверено с PHP 8.5.11 на Windows. Нужны PHP CLI и включённые расширения `PDO`, `pdo_sqlite`.

### 1. Получить проект

```powershell
git clone https://github.com/daniilboriskin21-eng/film-catalog.git
cd film-catalog
```

Если проект уже скачан, открой терминал в его корневой папке.

### 2. Проверить PHP

```powershell
php -v
php -m
```

В списке модулей должны присутствовать `PDO` и `pdo_sqlite`. Путь к используемому файлу настроек показывает команда `php --ini`. Если `pdo_sqlite` отсутствует, включи `extension=pdo_sqlite` в `php.ini` и укажи корректный `extension_dir`. После изменения настроек перезапусти PHP-сервер.

### 3. Создать и заполнить базу

Папка `storage` и файл базы не поставляются с данными репозитория. Перед инициализацией создай папку:

```powershell
New-Item -ItemType Directory -Force -Path storage | Out-Null
php database/init.php
```

Скрипт создаёт `storage/films.sqlite`, таблицу `movies` и добавляет шесть начальных записей. Ожидаемый вывод:

```text
Таблица movies готова
Начальные данные загружены
```

Повторный запуск не создаёт дубликаты: записи с существующими `id` пропускаются. Изменения в `seed.sql` не обновляют уже существующие фильмы, а изменения в `schema.sql` не изменяют существующую таблицу автоматически.

### 4. Запустить сервер

```powershell
php -S 127.0.0.1:8000 -t public
```

Открой [каталог](http://127.0.0.1:8000/). Терминал должен оставаться работающим; остановка сервера — `Ctrl+C`. Встроенный сервер используется для локальной разработки.

Корень сервера — `public`, поэтому файлы базы и внутренний PHP-код остаются вне публичной директории. Live Server и открытие HTML как файла не выполняют PHP API.

## API

`GET /api/movies.php` читает фильмы из SQLite и возвращает JSON-массив, упорядоченный по `id`.

Каждый объект содержит `id` (строка), `title`, `year` (число), `genre`, `rating` (число) и `poster` (путь к изображению). Строковый `id` сохраняет совместимость с избранным в браузере.

Проверить ответ можно по адресу [API каталога](http://127.0.0.1:8000/api/movies.php). При успехе сервер отвечает статусом `200`. При перехваченной ошибке — статусом `500` и JSON:

```json
{"error":"Не удалось загрузить фильмы"}
```

Подробности ошибки записываются в серверный журнал через `error_log`.

## Проверка после изменений

1. Убедись, что отображаются шесть карточек и загружаются постеры.
2. Найди фильм по части названия, затем проверь несуществующий и пустой запрос.
3. Добавь два фильма в избранное и проверь счётчик и соответствующий раздел.
4. Обнови страницу: выбранные фильмы должны сохраниться.
5. Удали последний фильм из избранного: должно появиться сообщение о пустом списке.
