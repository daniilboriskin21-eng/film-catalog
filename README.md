# КиноПолка — каталог фильмов с избранным

Учебный pet-проект на HTML, CSS, JavaScript и PHP. Фильмы хранятся в SQLite, клиент получает данные через JSON API. Сборщик фронтенда, npm и Composer для запуска не требуются.

## Возможности

- Адаптивный каталог с постерами, названием, годом, жанром и рейтингом.
- Поиск по части названия без учёта регистра и пробелов по краям запроса.
- Страница фильма с описанием и кнопкой избранного.
- Избранное в localStorage, счётчик и совместная работа поиска с режимом избранного.
- Очистка ID удалённых фильмов из избранного после успешной загрузки полного каталога.
- Вход и выход администратора через PHP-сессии.
- Админ-панель: список фильмов, добавление, редактирование и удаление с подтверждением.
- Серверная проверка полей, авторизации и CSRF-токена при изменении фильмов.
- Сообщения о загрузке, пустом результате и ошибках; блокировка кнопок на время отправки.

Избранное привязано к текущему браузеру и адресу сайта, включая порт. Пользовательских аккаунтов и синхронизации избранного между устройствами нет. Начальные рейтинги демонстрационные.

## Стек

HTML, CSS, JavaScript (ES-модули, fetch, localStorage), PHP, PDO и SQLite.

## Локальный запуск

Команды выполняются в PowerShell из корня проекта. Для разработки используется PHP 8.5.11. Нужны PHP CLI и расширения PDO и pdo_sqlite.

### 1. Скачать проект и проверить PHP

~~~powershell
git clone https://github.com/daniilboriskin21-eng/film-catalog.git
cd film-catalog
php -v
php -m
~~~

В списке модулей должны быть PDO и pdo_sqlite. Команда php --ini показывает используемый файл настроек. Если расширение отсутствует, включи extension=pdo_sqlite в php.ini, проверь extension_dir и перезапусти PHP-сервер.

### 2. Подготовить базу

~~~powershell
New-Item -ItemType Directory -Force -Path storage | Out-Null
php database/init.php
~~~

Скрипт создаёт storage/films.sqlite, таблицы фильмов и администраторов, применяет предусмотренные миграции и загружает шесть начальных фильмов.

Повторный запуск не дублирует существующие ID. Однако удалённые начальные записи могут появиться снова, а пустые описания начальных фильмов заполняются из seed.sql. Это инструмент начальной подготовки, а не команда для повседневного запуска сайта. Перед повторной инициализацией существующей базы сделай её резервную копию.

### 3. Создать администратора

~~~powershell
php database/create_admin.php
~~~

Введи уникальный логин, пароль и его подтверждение. Скрипт проверяет длину пароля через strlen: минимум 12 байт. Ввод пароля в терминале сейчас видим. В базе сохраняется хеш пароля; готовая учётная запись вместе с репозиторием не поставляется.

### 4. Запустить сайт

~~~powershell
php -S 127.0.0.1:8000 -t public
~~~

- [Каталог](http://127.0.0.1:8000/)
- [Вход администратора](http://127.0.0.1:8000/login.html)
- [Управление фильмами](http://127.0.0.1:8000/admin.html)

Терминал должен оставаться открытым. Остановка — Ctrl+C. Корень сервера — public: база и внутренние PHP-модули находятся вне него. Live Server и открытие HTML как файла не выполняют PHP API.

## Управление фильмами

После входа можно добавить фильм, перейти к редактированию или удалить его из списка. При удалении требуется подтверждение. Файл постера автоматически не удаляется.

Все шесть полей обязательны. Год — целое число от 1888 до следующего года, рейтинг — число от 0 до 10.

Постеры пока добавляются вручную в public/assets/images/posters/. В форме укажи, например, assets/images/posters/interstellar.webp. Начальный ./ допускается и удаляется перед сохранением. Имя файла может содержать латинские буквы, цифры, дефис и подчёркивание; поддерживаются расширения jpg, jpeg, png, webp в нижнем регистре. Файл должен существовать. Загрузки изображений через форму пока нет.

## API

Все ответы — JSON. Ошибки содержат поле error; подробности внутренних ошибок записываются в серверный журнал.

| Метод | Адрес | Назначение |
|---|---|---|
| GET | /api/movies.php | Полный список фильмов |
| GET | /api/movie.php?id=1 | Один фильм с описанием |
| POST | /api/login.php | Вход: username, password |
| GET | /api/session.php | Статус входа и CSRF-токен авторизованной сессии |
| POST | /api/logout.php | Завершение сессии |
| POST | /api/create_movie.php | Создание фильма, ответ 201 |
| POST | /api/update_movie.php | Изменение фильма, ответ 200 |
| POST | /api/delete_movie.php | Удаление фильма, ответ 200 |

Создание и обновление принимают поля title, year, genre, rating, poster, description через FormData. Обновлению и удалению также нужен id. Все три операции требуют сессию администратора и заголовок X-CSRF-Token.

Используются коды ошибок 400 (неверные данные), 401 (нет входа или неверные данные входа), 403 (неверный CSRF-токен), 404 (фильм не найден), 405 (метод не разрешён), 500 (ошибка сервера). В API чтения ID фильма возвращается строкой для совместимости с избранным.

## Ручная проверка

1. Открой каталог, проверь постеры, поиск, пустой результат и переход к фильму.
2. Добавь фильмы в избранное, обнови страницу и проверь счётчик и фильтрацию.
3. В приватном окне открой админ-панель: должна открыться страница входа. Проверь неправильный пароль, вход и выход.
4. Создай тестовый фильм, открой его, измени описание и проверь сохранение после обновления страницы.
5. Проверь неверный путь постера: ошибка должна сохранять введённые значения и возвращать доступность кнопки.
6. Добавь тестовый фильм в избранное. Проверь отмену удаления, затем удали его с подтверждением. После загрузки каталога его ID должен исчезнуть из избранного.
7. Проверь страницы на узком экране и навигацию клавишей Tab.

## Ограничения и дальнейшее развитие

- Нет загрузки постеров через форму, пагинации, сортировки и фильтров по жанру и году.
- Нет регистрации пользователей и серверного избранного.
- Настройки сессии рассчитаны на локальный HTTP. Для публикации нужны HTTPS и secure: true для cookie, отключение вывода PHP-ошибок посетителям и ограничение попыток входа.
- Встроенный сервер PHP предназначен для разработки. Публичное размещение и полная проверка MVP остаются отдельным этапом.
